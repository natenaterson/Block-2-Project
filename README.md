# Block-2-Project
This is for the Block 2 Project assignment

This project is designed to make using the terminal easier and more accessible. As someone with dyslexia, I sometimes struggle with spelling, and the terminal requires commands to be spelled correctly to work. This project aims to address that problem by adding a spell checker to the terminal, making it easier for users to enter commands without worrying as much about spelling mistakes. The project will also display the most frequently used commands, allowing users to access common commands more easily and improve their workflow.
